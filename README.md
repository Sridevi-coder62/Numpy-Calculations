# 🐍 Python & NumPy Practice

This repository contains my **Python List and NumPy array practice programs**. The exercises focus on building strong programming fundamentals through practical problem-solving and array manipulation.

## 📚 Topics Covered

* Find Middle Element(s) in a List
* Find Border Elements in a 2D NumPy Array
* Move Zeros to the End of a List
* Rotate a Matrix 90° Clockwise
* Find the First Repeating Element and Its Index
* Find the Layer With the Highest Sum in a 3D NumPy Array

## 🛠️ Technologies Used

* 🐍 **Python**
* 🔢 **NumPy**
* 📓 **Google Colab / Jupyter Notebook**

## 🎯 Objective

The objective of this repository is to strengthen my **Python and NumPy fundamentals** through hands-on practice involving:

* Indexing and slicing
* Loops and conditional statements
* List manipulation
* NumPy arrays
* 2D and 3D array operations
* Matrix manipulation
* Problem-solving and logical thinking

## 📂 Repository Contents

The repository contains Python programs and notebooks demonstrating solutions to the practice problems listed above.
